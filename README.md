# AI-AutoCAD

Программа двумерного черчения в браузере, устроенная как AutoCAD: командная строка, привязки, слои,
размеры, штриховки, блоки, чертежи DWG и DXF — с оформлением по ЕСКД (рамки, основная надпись по
ГОСТ 2.104, типы линий по ГОСТ 2.303), помощником на вашей локальной модели и чертежами на вашем сервере.
Ставится папкой на сервер с nginx и PHP: инструкция — [`studio/README.ru.md`](studio/README.ru.md), что
нового — [`studio/CHANGES.ru.md`](studio/CHANGES.ru.md). Готовые сборки — в Releases.

Основано на [CADCraft](https://github.com/storytold/cadcraft) (MIT OR Apache-2.0); описание исходного
проекта — [`docs/README-upstream.md`](docs/README-upstream.md), лицензии — [`NOTICE`](NOTICE).
AutoCAD — товарный знак Autodesk, Inc.; AI-AutoCAD с Autodesk не связан.
