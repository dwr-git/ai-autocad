# AI-AutoCAD — установка на сервер

Программа двумерного черчения в браузере, устроенная как AutoCAD: командная строка, объектные привязки,
ОРТО и полярное отслеживание, слои, типы и толщины линий, размеры, штриховки, блоки, листы и печать в PDF.
Чертежи DWG и DXF. Со встроенным помощником на вашей локальной модели, оформлением по ЕСКД и чертежами на
вашем сервере. На сервере нужны только **nginx + PHP + Ollama** (или другой сервер модели) — то, что у вас уже
есть. Ничего компилировать не нужно. Редактор полностью автономный: всё загружается из его папки, интернет и
сторонние сайты не нужны.

## Установка (5 минут)

1. **Скачайте готовую сборку.** GitHub → репозиторий `ai-autocad` → справа **Releases** →
   верхняя «Сборка N — дата» (с пометкой Latest) → файл `ai-autocad-build-N-ГГГГ-ММ-ДД.zip`.
   Какая сборка стоит у вас, видно в шапке панели помощника: «Модель: … · сборка N».
2. **Распакуйте** — внутри одна папка `ai-autocad`.
3. **Положите её на сервер** рядом с остальными приложениями: `/app/src/ai-autocad/`.
   Папку можно назвать как угодно — все пути внутри относительные. Помощник и хранилище сами найдут
   ваш `auth.php` на два уровня выше и через него — `config.php`, `.env`, адрес сервера модели и модель.
4. **Папка для чертежей создаётся сама**: `storage/ai-autocad` рядом с корнем сайта.
   Проверка: `https://ваш-домен/ai-autocad/api/files.php` → `{"ok":true,…}`.
5. **nginx** — готовые блоки в `nginx.conf.example` (большие запросы и долгое ожидание модели).
6. **Откройте** `https://ваш-домен/ai-autocad/`.

Обновление — то же самое: скачать новый zip и заменить папку (свой `studio/config.js` сохраните).
Каждая сборка лежит в своей папке `b/<номер>/`, а `index.php` открывает самую новую целую, поэтому
программа заливки не может смешать файлы двух сборок. Если заливаете по FTP, лучше включить «Перезаписывать всегда».

Для проверки без входа в систему на своём компьютере:
`AI_AUTOCAD_ALLOW_ANON=1 php -S 127.0.0.1:8080 -t ai-autocad` и откройте `http://127.0.0.1:8080/`.

## С чего начинается

При первом запуске интерфейс русский, тема — **Фирменная**, сразу открыт чистый чертёж в **миллиметрах**
(пределы — лист A3), «Сохранить как» предлагает **DWG** (версия 2018). Новые чертежи (Ctrl+N) тоже в
миллиметрах. Другой язык, тема и формат сохранения — «Сервис › Настройки» и меню «Вид».

## Чертежи

- **Ctrl+S** сохраняет чертёж в «Мои чертежи» на сервере (значок папки в панели помощника). Первый раз
  спросит имя, дальше сохраняет туда же. «Сохранить как…» — копия под новым именем; формат — по расширению
  (`.dwg`, `.dxf` или `.dwt`).
- **Мои чертежи**: список с датой и размером, поиск, открыть, переименовать, удалить (в корзину `.trash`),
  «С компьютера…» — открыть файл с компьютера. Сервер принимает только настоящие чертежи: DWG и DWT
  начинаются с версии формата `AC10…`, двоичный DXF — с `AutoCAD Binary DXF`, текстовый DXF — с кода группы 0.
- У каждого пользователя своя папка. Чертёж с сервера сохраняется туда сам раз в минуту, если в нём есть
  изменения (и не идёт команда). Если сохранить не удалось (нет связи, сервер отказал), файл скачивается в
  браузере, а копия остаётся в браузере, и панель предложит её открыть.
- **Печать и экспорт** (Файл › Печать, Экспорт в PDF, Экспорт) — файлы скачиваются в браузере. Быстрые
  задачи — «Скачать PDF A4» и «Скачать PDF A3» (весь чертёж на лист, с толщинами линий).

## ЕСКД

Быстрые задачи (значок с квадратиками) → **ЕСКД**:

- **Рамка A4–A1 со штампом**: внешняя рамка листа (тонкая линия), внутренняя — поля 20 мм слева и 5 мм с
  остальных сторон (основная линия), основная надпись по ГОСТ 2.104 форма 1 (185×55 мм) в правом нижнем углу
  с подписями граф. Рамка ставится справа от чертежа (или в начале координат на пустом чертеже), в масштабе 1:1.
- **Слои и типы линий ГОСТ** (ГОСТ 2.303): слои «Основная» (0,5 мм), «Тонкая», «Осевая» (штрихпунктирная),
  «Штриховая», «Размеры», «Текст», «Штриховка», «Рамка»; свои типы линий ГОСТ_ШТРИХОВАЯ, ГОСТ_ШТРИХПУНКТИРНАЯ,
  ГОСТ_ШТРИХПУНКТИР_2Т; текстовый стиль «ГОСТ 2.304» (наклон 15°) и размерный стиль «ГОСТ 2.307»
  (высота текста 3,5 мм, стрелки 3,5 мм).
- **Размеры у выделенного**: отрезки — параллельный размер, окружности — диаметр, дуги — радиус, прямоугольник
  и другие замкнутые полилинии — габаритные размеры.
- **Проверить чертёж**: незамкнутые контуры, объекты на слое 0, типы линий не по ГОСТ, толщины, текст и размеры.

**Шрифт чертежа.** Чертёжного шрифта по ГОСТ 2.304 среди открытых шрифтов нет, поэтому стиль «ГОСТ 2.304»
использует `arial.ttf` с наклоном 15°: в браузере его заменяет **Liberation Sans** (метрически совместимый с
Arial, с кириллицей), в AutoCAD у получателя будет Arial. Если у предприятия есть лицензированные чертёжные
шрифты (SHX или TTF по ГОСТ 2.304), положите их в `storage/ai-autocad/fonts/` — надписи, которые на них
ссылаются, будут нарисованы ими у всех пользователей.

## Шрифты

- **Шрифты-двойники уже внутри** (папка `fonts/`): Liberation Sans — по размерам Arial, Liberation Serif —
  Times New Roman, Liberation Mono — Courier New. В них есть кириллица (встроенный чертёжный шрифт редактора —
  только латиница, а в браузере нет системных шрифтов). Ими же рисуются надписи, шрифт которых не найден.
- **Шрифты организации.** Положите в `storage/ai-autocad/fonts/` (папка создаётся сама, рядом с папками
  пользователей) шрифты, на которые у организации есть лицензия: TrueType (`.ttf`, `.otf`) и чертёжные SHX
  (`.shx`). AI-AutoCAD загрузит их у всех пользователей.

## Помощник

- **Совет** — объясняет, какую команду вызвать и что ответить на её запросы, описывает чертёж, проверяет
  оформление по ЕСКД. Ничего не меняет.
- **Сделай** — сам чертит: отрезки, полилинии, окружности, надписи, размеры, слои; рамку и штамп; командами
  с параметрами или прямо в командной строке, как пользователь. Каждое действие отменяется (Ctrl+Z). Сколько
  шагов подряд делать и спрашивать ли перед удалением — «Настройки» внизу панели.
- Помощник знает основы ЕСКД: форматы A4–A0 и рамку (ГОСТ 2.301), основную надпись (ГОСТ 2.104), масштабы
  (ГОСТ 2.302), типы линий (ГОСТ 2.303), шрифт (ГОСТ 2.304), размеры (ГОСТ 2.307), технические требования (ГОСТ 2.316).
- **Быстрые задачи**: рамки со штампом, слои ГОСТ, размеры у выделенного, проверка, PDF — и готовые просьбы
  помощнику (заполнить штамп, технические требования, деталь по описанию, удалить дубликаты).
- **Быстрая строка — Ctrl+Shift+Пробел.**

### ИИ у выделения

Выделите надписи (однострочный или многострочный текст) и нажмите **ИИ** справа в панели инструментов, или
правая кнопка на чертеже → **ИИ у выделения…**, или **Ctrl+Alt+Пробел**. В меню: исправить ошибки, поправить
надпись, сокращения по ГОСТ 2.316, сократить, прописными буквами; оформить технические требования, примечание,
наименование для штампа, пронумеровать пункты; перевод; проверить надписи чертежа, описать чертёж. В строке
сверху можно написать свою просьбу и нажать Enter.

Модель видит все надписи чертежа, а работает с выделенными. Ответ сначала показывается в окошке:
**Заменить надпись** (или **Заменить по строкам**, если выделено несколько), **Новой надписью ниже**,
**Копировать** или **Ещё вариант**. Отмена — Ctrl+Z. Задания для модели — в `api/context.php`.

## Оформление

Тема редактора — **Фирменная** (по умолчанию), **Светлая** или **Тёмная**: значок палитры в панели помощника
или «Вид › Тема интерфейса». Выбор запоминается в браузере. Поле чертежа (пространство модели) остаётся
тёмным, как принято в САПР; цвет поля — «Сервис › Настройки › Экран». Листы (компоновки) — белые. Домик
справа вверху ведёт обратно на сайт (адрес — `homeUrl` в `studio/config.js`).

## Настройки в `.env` (необязательно)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `AI_AUTOCAD_DATA_DIR` | Где хранить чертежи и шрифты организации | `storage/ai-autocad` рядом с корнем сайта |
| `AI_AUTOCAD_MODEL` | Модель помощника (нужны tools; для «глаза» — картинки) | `GLOBAL_MODEL` |
| `AI_AUTOCAD_LLM_URL` | Адрес Ollama или шлюза | `OLLAMA_IP:OLLAMA_PORT` |
| `AI_AUTOCAD_CONTEXT` | Размер контекста | `GLOBAL_MODEL_CONTEXT` или 32768 |
| `AI_AUTOCAD_TIMEOUT` | Сколько секунд ждать модель | 180 |
| `AI_AUTOCAD_MAX_TOKENS` | Длина ответа | 2048 |
| `AI_AUTOCAD_AUTH_FILE` | Путь к `auth.php`, если папка лежит не в `/app/src/` | ищется автоматически |
| `AI_AUTOCAD_TALERS_FILE` | `talers.php` кабинета для ИИ у выделения (цена операции и остаток) | `cabinet/talers.php` рядом с корнем сайта, если он есть |
| `AI_AUTOCAD_ALLOW_ANON` | `1` — без входа (только для проверки!) | выключено |

### Откуда помощник берёт модель

Главный источник — файл **.env** вашей системы. Помощник находит его сам: рядом с папкой приложения
и выше по папкам (обычно это `.env` в корне сайта или уровнем выше). Если .env лежит в другом месте,
укажите путь в переменной `AI_ENV_FILE`. Значения из .env важнее переменных окружения процесса:
если сервер запущен со старыми переменными, а .env поменяли, работает то, что написано в .env.

Порядок поиска (берётся первое найденное):

| Что | Где ищется |
|---|---|
| Адрес сервера модели | `AI_AUTOCAD_LLM_URL` → `LLM_URL`, `OLLAMA_URL`, `OLLAMA_HOST`, `OPENAI_BASE_URL` → `OLLAMA_IP` + `OLLAMA_PORT` → `$url_ollama` из config.php системы → `127.0.0.1:11434` |
| Модель | `AI_AUTOCAD_MODEL` → `GLOBAL_MODEL`, `LLM_MODEL`, `OLLAMA_MODEL`, `CHAT_MODEL`, `DEFAULT_MODEL` → `$global_model` из config.php → первая модель, которую отдаёт сам сервер |
| Размер контекста | `AI_AUTOCAD_CONTEXT` → `GLOBAL_MODEL_CONTEXT`, `LLM_CONTEXT`, `OLLAMA_CTXSIZE` → `$ollama_ctxsize` → 32768 |
| Ключ (если шлюз его требует) | `AI_AUTOCAD_API_KEY` → `LLM_API_KEY`, `OPENAI_API_KEY` |
| Протокол | `AI_AUTOCAD_LLM_API` или `LLM_API` = `ollama` / `openai`; без них определяется сам |

- **Любой сервер:** работает и с Ollama, и с OpenAI-совместимыми серверами (vLLM, GLM, LM Studio и
  другие). Адрес с `/v1` на конце считается OpenAI-совместимым. Если у адреса нет `/api/chat`
  (как у Ollama), помощник сам пробует `/v1/chat/completions`.
- **Любая модель:** имя модели сверяется со списком моделей сервера. Если такой модели там нет,
  берётся подходящая из списка. Если шлюз принимает имена-псевдонимы, которых нет в его списке
  (например `chat`), поставьте `LLM_MODEL_CHECK=0`.
- Если сервер не умеет вызывать инструменты, помощник сам переходит на текстовый протокол вызовов.
- **Как проверить:** наведите мышь на строку «Модель: …» в шапке панели помощника. Там написано,
  какая модель используется и из какой строки .env она взята. То же показывает адрес
  `api/assistant.php` в браузере.


## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Редактор не запускается | Под полосой загрузки написано, какой файл не пришёл и почему. Нужен браузер с WebGPU или WebGL2 |
| После заливки по FTP — старая версия | Программа заливки пропустила файлы того же размера: включите «Перезаписывать всегда» |
| В панели «Нужно войти в систему» | Вход в вашу систему в этом же браузере и на этом же домене |
| «Не удалось создать папку для файлов» | Создайте `storage/ai-autocad` и дайте PHP право записи, или задайте `AI_AUTOCAD_DATA_DIR` |
| «Содержимое не похоже на чертёж» | Файл повреждён или это не DWG/DXF (например, переименованный PDF) |
| Редактор остановился при открытии DWG | Чтение DWG в браузере ещё новое: сильно повреждённый файл может остановить редактор. Обновите страницу (чертежи с сервера сохранялись туда сами раз в минуту) и откройте этот файл в AutoCAD, сохраните как DXF |
| Ошибка 413 / 504 | `client_max_body_size` / `fastcgi_read_timeout` — см. `nginx.conf.example` |
| Надписи другим шрифтом | Положите шрифты чертежа (SHX или TTF) в `storage/ai-autocad/fonts/` и обновите страницу |

## Для разработчика

- Сборку делает GitHub Actions (`.github/workflows/studio.yml`) на каждое изменение ветки `main`.
- Мост редактора: `apps/cadcraft-web/src/bridge.rs` — `window.aiautocad.request(метод, параметры)`,
  те же методы, что у канала управления (`docs/control-protocol.md`). В консоли браузера:
  `await aiautocad.execute('line', {points: [[0, 0], [100, 0]]})`,
  `await aiautocad.request('cmdline.input', {text: 'circle 0,0 25'})`.
- Сохранение на сервер: обработчик выдачи файлов движка (`bridge::deliver`) → событие `aiautocad:save` →
  `api/files.php`; печать и экспорт скачиваются.
- ЕСКД: `studio/web/eskd.js` (рамки, основная надпись, слои, размеры, проверка), знания помощника —
  `studio_eskd_knowledge()` в `api/tools.php`.
- Русский интерфейс: `crates/ui-egui/src/i18n/ru.tsv` (английский текст → русский).
- Основано на открытом проекте CADCraft (github.com/storytold/cadcraft, MIT OR Apache-2.0) от команды
  ArtCraft; лицензии — в `NOTICE` и `LICENSE-*`. AutoCAD — товарный знак Autodesk, Inc.; AI-AutoCAD с Autodesk
  не связан.
